Q7. UART INTERRUPT FIVE CHAR COMMAND
=====================================

Board      : ARIES v2 (THEJAS32 SoC, VEGA ET1031 RISC-V core, 100 MHz)
SDK        : Lyra SDK, #include <vega/hal.h> and <vega/aries.h>, build with make
Onboard    : RGB LED on GPIOB (RGB_RED 8, RGB_GREEN 6, RGB_BLUE 7), ACTIVE-LOW
             -> use RGB_x_SET (on) / RGB_x_RST (off)
             LED_2 (5), LED_3 (4), BTN0 (3), BTN1 (2) active-low (pressed = 0),
             SWITCH0 (0), SWITCH1 (1) on GPIOB
UART       : huart0 over the board USB cable, 115200 8N1 (minicom)
Timers     : htimer0/1/2, LoadCount = MILLIS(t) with #define MILLIS(t) ((t)*100000)

Source     : class RISC-V practice sheet, Question 7

Initialize UART0 and receive exactly five characters using UART_Receive_IT().
When all five characters have been received, implement UART_RxCpltCallback()
to notify the main loop that a command is ready.

The main loop must then:
- Echo the complete five-character command.
- Count how many characters are vowels.
- Count how many characters are digits.
- Print both counts over UART.
- Arm the next five-character receive operation.

Do not transmit from the UART receive callback. Use a shared buffer and a
volatile completion flag.

Required concepts:
- UART_Receive_IT()
- UART_RxCpltCallback()
- fixed-length interrupt reception
- shared buffers and volatile flags

Reference example:
- examples/UART/UART_Interrupt/uart_int.c


======================================================================
SOLUTION
======================================================================

Copy everything below into main.c, in the same folder as the
Makefile from this RISC-V folder, then: make  /  make flash
------------------------------------------------------------
#include <vega/hal.h>
#include <vega/aries.h>
#include <stdio.h>
#include <string.h>

char buf[6];
volatile uint8_t got =0;
char msg[64];

void UART_RxCpltCallback(UART_Handle_t *huart)
{
	got =1;
}

int main(void)
{
	UART_Init(&huart0);
	UART_Receive_IT(&huart0, buf, 5);

	while(1)
	{
		if(got)
		{
			got =0;
			buf[5] = 0;
			int v =0;
			int d =0;

			sprintf(msg, "\r\nCommand: %s\r\n", buf);
			UART_Transmit(&huart0, msg, strlen(msg));

			for(int i=0 ; i<5 ; i++)
			{
				char c = buf[i];
				if(c=='a' || c=='e' || c=='i' || c=='o' || c=='u' || c=='A' || c=='E' || c=='I' || c=='O' || c=='U')
				{
					v++;
				}
				else if(c >= '0' && c <= '9')
				{
					d++;
				}
			}
			sprintf(msg, "Vowels: %d Digits: %d\r\n", v, d);
			UART_Transmit(&huart0, msg, strlen(msg));

			UART_Receive_IT(&huart0, buf, 5);
		}
	}
}
