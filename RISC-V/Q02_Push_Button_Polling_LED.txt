Q2. PUSH BUTTON POLLING LED
============================

Board      : ARIES v2 (THEJAS32 SoC, VEGA ET1031 RISC-V core, 100 MHz)
SDK        : Lyra SDK, #include <vega/hal.h> and <vega/aries.h>, build with make
Onboard    : RGB LED on GPIOB (RGB_RED 8, RGB_GREEN 6, RGB_BLUE 7), ACTIVE-LOW
             -> use RGB_x_SET (on) / RGB_x_RST (off)
             LED_2 (5), LED_3 (4), BTN0 (3), BTN1 (2) active-low (pressed = 0),
             SWITCH0 (0), SWITCH1 (1) on GPIOB
UART       : huart0 over the board USB cable, 115200 8N1 (minicom)
Timers     : htimer0/1/2, LoadCount = MILLIS(t) with #define MILLIS(t) ((t)*100000)

Source     : class RISC-V practice sheet, Question 2

Configure GPIOB pins 2 and 3 as digital inputs and configure the three ARIESv2
RGB pins as outputs. Continuously poll the two push-button inputs.

Required behavior:
- Button 0 pressed: turn on the green LED only.
- Button 1 pressed: turn on the blue LED only.
- Neither button pressed: turn on the red LED only.
- All other RGB colors must be turned off whenever one color is selected.

Add a simple debounce delay so that one button press does not cause visible
flickering. Do not use interrupts in this assignment.

Required concepts:
- GPIO input/output configuration
- GPIO_ReadPin()
- polling and conditional logic

Reference example:
- examples/GPIO/GPIO_Polling/main.c


======================================================================
SOLUTION
======================================================================

Copy everything below into main.c, in the same folder as the
Makefile from this RISC-V folder, then: make  /  make flash
------------------------------------------------------------
#include <vega/hal.h>
#include <vega/aries.h>

int main(void)
{
	GPIO_Init(GPIOB, RGB_RED, GPIO_OUT);
	GPIO_Init(GPIOB, RGB_GREEN, GPIO_OUT);
	GPIO_Init(GPIOB, RGB_BLUE, GPIO_OUT);
	GPIO_Init(GPIOB, BTN0, GPIO_IN);
	GPIO_Init(GPIOB, BTN1, GPIO_IN);

	while(1)
	{
		RGB_RED_RST;
		RGB_GREEN_RST;
		RGB_BLUE_RST;

		if(GPIO_ReadPin(GPIOB, BTN0) == 0)        /* pressed = 0 */
		{
			RGB_GREEN_SET;
		}
		else if(GPIO_ReadPin(GPIOB, BTN1) == 0)
		{
			RGB_BLUE_SET;
		}
		else
		{
			RGB_RED_SET;
		}
		delayms(20);   /* debounce */
	}
}
