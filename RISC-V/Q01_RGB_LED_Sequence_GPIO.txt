Q1. RGB LED SEQUENCE GPIO
==========================

Board      : ARIES v2 (THEJAS32 SoC, VEGA ET1031 RISC-V core, 100 MHz)
SDK        : Lyra SDK, #include <vega/hal.h> and <vega/aries.h>, build with make
Onboard    : RGB LED on GPIOB (RGB_RED 8, RGB_GREEN 6, RGB_BLUE 7), ACTIVE-LOW
             -> use RGB_x_SET (on) / RGB_x_RST (off)
             LED_2 (5), LED_3 (4), BTN0 (3), BTN1 (2) active-low (pressed = 0),
             SWITCH0 (0), SWITCH1 (1) on GPIOB
UART       : huart0 over the board USB cable, 115200 8N1 (minicom)
Timers     : htimer0/1/2, LoadCount = MILLIS(t) with #define MILLIS(t) ((t)*100000)

Source     : class RISC-V practice sheet, Question 1

Write a program that configures the ARIESv2 RGB LED pins as GPIO outputs.
Turn on the red, green, and blue LEDs one at a time in the following order:

    RED -> GREEN -> BLUE -> repeat

Keep each LED on for 500 ms and switch all LEDs off before selecting the next
color. Use delayms() for timing.

Required concepts:
- GPIO_Init()
- GPIO_SetPin() / GPIO_ResetPin(), or the ARIES RGB macros
- delayms()
- active-low LED operation

Reference examples:
- examples/Blinky/blinky.c
- hal/include/aries.h


======================================================================
SOLUTION
======================================================================

Copy everything below into main.c, in the same folder as the
Makefile from this RISC-V folder, then: make  /  make flash
------------------------------------------------------------
#include <vega/hal.h>
#include <vega/aries.h>

int main(void)
{
	GPIO_Init(GPIOB, RGB_RED, GPIO_OUT);
	GPIO_Init(GPIOB, RGB_GREEN, GPIO_OUT);
	GPIO_Init(GPIOB, RGB_BLUE, GPIO_OUT);

	RGB_RED_RST;
	RGB_GREEN_RST;
	RGB_BLUE_RST;

	while(1)
	{
		RGB_RED_SET;
		delayms(500);
		RGB_RED_RST;

		RGB_GREEN_SET;
		delayms(500);
		RGB_GREEN_RST;

		RGB_BLUE_SET;
		delayms(500);
		RGB_BLUE_RST;
	}
}
