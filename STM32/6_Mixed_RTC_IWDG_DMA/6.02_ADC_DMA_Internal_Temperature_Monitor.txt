6.2  ADC DMA INTERNAL TEMPERATURE MONITOR
=========================================

Board      : STM32F407G-DISC1 (Discovery)
Tool       : STM32CubeIDE, HAL
Clock      : HSI 16 MHz (timer clock 16 MHz) unless stated
Debug      : SYS -> Serial Wire, always
Onboard    : PD12 green, PD13 orange, PD14 red, PD15 blue, PA0 user button
             (HIGH when pressed), LIS3DSH accelerometer on SPI1
             (PA5 SCK, PA6 MISO, PA7 MOSI, PE3 CS), internal ADC temp/VREFINT

Source     : class mixed-scenario sheet, Q7 (no external components)

Scenario:
Measure the MCU's internal temperature sensor without connecting an external
analog source. Also sample VREFINT so that the ADC results can be checked for
reasonable supply-voltage variation.

Tasks:
1. Configure ADC1 to scan the internal temperature-sensor channel and
   VREFINT. Use the long sampling time recommended for internal channels.
2. Configure a timer trigger at 100 ms and use DMA in circular mode to fill
   a buffer containing at least 16 samples of each channel.
3. Average the latest 16 temperature-sensor readings and the latest 16
   VREFINT readings before updating the application state.
4. Convert the readings using the STM32F407 reference information and record
   the assumptions used for VDDA and temperature calibration. Relative
   temperature thresholds are acceptable for a beginner implementation.
5. Display four temperature ranges with PD12-PD15 and blink PD14 if the
   selected high-temperature threshold is exceeded.
6. Use PA0 to switch between live monitoring and a frozen snapshot mode.
7. Start ADC-DMA operation with HAL and verify the circular buffer, transfer
   position and averaged values in the debugger.
8. Explain why an internal ADC channel satisfies the no-external-components
   requirement and why the reading may change as the MCU warms up.

======================================================================
SOLUTION
======================================================================

STEP 1 - CubeMX (.ioc) settings
------------------------------------------------------------
SYS               | Debug = Serial Wire
RCC               | default (HSI 16 MHz)
PD12-PD15         | GPIO_Output
PA0               | GPIO_EXTI0 rising, NVIC EXTI line0 ON
TIM3              | PSC 15999, ARR 99 (100 ms), Trigger Event Selection = Update Event
ADC1              | Temperature Sensor + Vrefint Channel ON
ADC1 settings     | Scan ON, Continuous OFF, DMA Continuous Requests ON,
                  | Number of conversions 2, External trigger = Timer 3 Trigger Out, rising
ADC1 Rank1/Rank2  | Temperature Sensor / Vrefint, both 480 cycles
DMA (ADC1)        | DMA2 Stream0, Circular, Half Word / Half Word, memory increment
------------------------------------------------------------

STEP 2 - replace the WHOLE Core/Src/main.c with the code below
------------------------------------------------------------

int main(void)
{
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();
    MX_DMA_Init();
    MX_ADC1_Init();
    MX_TIM3_Init();

    /* USER CODE BEGIN 2 */
	HAL_ADC_Start_DMA(&hadc1, (uint32_t*)buf, 32);
	HAL_TIM_Base_Start(&htim3);
	HAL_Delay(2000);   /* wait for first 16 samples */
    /* USER CODE END 2 */

    while (1)
    {
    /* USER CODE BEGIN 3 */
	if(frozen == 0)
	{
		int sumT =0;
		int sumV =0;
		for(int i=0 ; i<32 ; i+=2)
		{
			sumT += buf[i];
			sumV += buf[i+1];
		}
		vdda = (1.21f*4095.0f)/(sumV/16.0f);
		vsense = (sumT/16.0f)*vdda/4095.0f;
		temp = (vsense - 0.76f)/0.0025f + 25.0f;
		if(first)
		{
			first =0;
			start =temp;
		}
	}

	float d = temp - start;
	HAL_GPIO_WritePin(GPIOD, GPIO_PIN_12|GPIO_PIN_13|GPIO_PIN_15, 0);
	if(d < 1)
	{
		HAL_GPIO_WritePin(GPIOD, GPIO_PIN_12, 1);
		HAL_GPIO_WritePin(GPIOD, GPIO_PIN_14, 0);
	}
	else if(d < 2)
	{
		HAL_GPIO_WritePin(GPIOD, GPIO_PIN_12|GPIO_PIN_13, 1);
		HAL_GPIO_WritePin(GPIOD, GPIO_PIN_14, 0);
	}
	else if(d < 3)
	{
		HAL_GPIO_WritePin(GPIOD, GPIO_PIN_12|GPIO_PIN_13|GPIO_PIN_15, 1);
		HAL_GPIO_WritePin(GPIOD, GPIO_PIN_14, 0);
	}
	else
	{
		HAL_GPIO_WritePin(GPIOD, GPIO_PIN_12|GPIO_PIN_13|GPIO_PIN_15, 1);
		HAL_GPIO_TogglePin(GPIOD, GPIO_PIN_14);   /* high: blink red */
	}
	HAL_Delay(250);
    /* USER CODE END 3 */
    }
}

void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
	uint32_t now = HAL_GetTick();
	if(GPIO_Pin == GPIO_PIN_0 && now-last>200)
	{
		last =now;
		if(frozen == 0)
		{
			frozen =1;
		}
		else
		{
			frozen =0;
		}
	}
}
