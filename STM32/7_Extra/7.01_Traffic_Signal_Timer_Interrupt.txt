7.01  TRAFFIC SIGNAL TIMER INTERRUPT
===================================

Board      : STM32F407G-DISC1 (Discovery)
Tool       : STM32CubeIDE, HAL
Clock      : HSI 16 MHz (timer clock 16 MHz) unless stated
Debug      : SYS -> Serial Wire, always
Onboard    : PD12 green, PD13 orange, PD14 red, PD15 blue, PA0 user button
             (HIGH when pressed), LIS3DSH accelerometer on SPI1
             (PA5 SCK, PA6 MISO, PA7 MOSI, PE3 CS), internal ADC temp/VREFINT

Source     : extra (classmate solution), class mixed-scenario sheet, Q1 (no external components)

Scenario:
Create a pedestrian-road traffic sequence using the onboard LEDs. The green
LED must remain ON for 2 seconds, then the red LED must remain ON for
1 second, and the sequence must repeat continuously.

LED allocation:
- PD12 green: road GO
- PD14 red  : road STOP
- PD13 and PD15: OFF during this question

Use TIM2 in base-timer interrupt mode. The update interrupt must occur every
100 ms, and software counters must create the longer intervals.

Tasks:
1. Configure PD12-PD15 as GPIO outputs.
2. Configure TIM2 with the internal clock.
3. Select Prescaler and Counter Period values for a 100 ms interrupt.
   With a 16 MHz timer clock, one suitable choice is PSC = 15999 and
   ARR = 99.
4. Enable the TIM2 global interrupt in the NVIC.
5. Start TIM2 with HAL_TIM_Base_Start_IT().
6. Implement the sequence in HAL_TIM_PeriodElapsedCallback(). Count
   20 interrupts for 2 seconds and 10 interrupts for 1 second.
7. Use a state variable so that only one LED state is active at a time.
8. Keep SWD enabled and observe the state and software counters in the
   debugger.

======================================================================
SOLUTION
======================================================================

STEP 1 - CubeMX (.ioc) settings
------------------------------------------------------------
SYS               | Debug = Serial Wire
RCC               | default (HSI 16 MHz)
PD12, PD14        | GPIO_Output
TIM4              | Clock Source = Internal Clock
TIM4 params       | Prescaler 16000, Counter Period 100 (about 100 ms), Trigger Event = Update Event
NVIC              | TIM4 global interrupt = ticked
Note              | His version uses TIM4 instead of TIM2. Count 0-19 = green, 20-29 = red.
------------------------------------------------------------

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
	if(htim->Instance == TIM4)
	{
		count++;
		if(count < 20)
		{
			HAL_GPIO_WritePin(GPIOD, GPIO_PIN_12, GPIO_PIN_SET);
			HAL_GPIO_WritePin(GPIOD, GPIO_PIN_14, GPIO_PIN_RESET);
		}
		else if(count < 30)
		{
			HAL_GPIO_WritePin(GPIOD, GPIO_PIN_14, GPIO_PIN_SET);
			HAL_GPIO_WritePin(GPIOD, GPIO_PIN_12, GPIO_PIN_RESET);
		}
		else{
			HAL_GPIO_WritePin(GPIOD, GPIO_PIN_12, GPIO_PIN_RESET);
			HAL_GPIO_WritePin(GPIOD, GPIO_PIN_14, GPIO_PIN_RESET);
		}

		if(count > 31)
		{
			count = 0;
		}
	}
}
