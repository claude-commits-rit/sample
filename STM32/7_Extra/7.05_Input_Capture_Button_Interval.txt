7.05  INPUT CAPTURE BUTTON INTERVAL
==================================

Board      : STM32F407G-DISC1 (Discovery)
Tool       : STM32CubeIDE, HAL
Clock      : HSI 16 MHz (timer clock 16 MHz) unless stated
Debug      : SYS -> Serial Wire, always
Onboard    : PD12 green, PD13 orange, PD14 red, PD15 blue, PA0 user button
             (HIGH when pressed), LIS3DSH accelerometer on SPI1
             (PA5 SCK, PA6 MISO, PA7 MOSI, PE3 CS), internal ADC temp/VREFINT

Source     : extra (classmate solution), class mixed-scenario sheet, Q5 (no external components)

Scenario:
The User button on PA0 is pressed twice. Measure the time between the two
valid rising edges in milliseconds using timer input capture.

Use TIM2 Channel 1. PA0 is the onboard button and also supports the TIM2_CH1
alternate function on the STM32F407.

Tasks:
1. Configure TIM2 for a 1 ms timer tick. Use an ARR large enough to allow
   the counter to run between button presses.
2. Configure PA0 for TIM2_CH1 input capture using the board's button
   connection and the correct pull configuration.
3. Configure Channel 1 for Input Capture Direct Mode with Rising Edge
   polarity.
4. Select a suitable input filter and add software debounce so that switch
   bounce is not interpreted as multiple presses.
5. Enable the TIM2 global interrupt and start capture with
   HAL_TIM_IC_Start_IT().
6. Store the first and second timestamps in HAL_TIM_IC_CaptureCallback().
7. Calculate the elapsed time, including the case where the timer counter
   overflows between captures.
8. Display a completed measurement by briefly blinking PD15 and inspect the
   measured interval in the debugger.
9. Keep SWD enabled.

======================================================================
SOLUTION
======================================================================

STEP 1 - CubeMX (.ioc) settings
------------------------------------------------------------
SYS               | Debug = Serial Wire
RCC               | default (HSI 16 MHz)
TIM2              | Clock Source = Internal Clock, Channel1 = Input Capture direct mode (PA0)
TIM2 params       | Prescaler 16000 (1 ms tick), Counter Period 4294967295, Rising edge, Input Filter 15
NVIC              | TIM2 global interrupt = ticked
Debugger          | watch result (ms between two presses)
------------------------------------------------------------

/* USER CODE BEGIN 4 */
void HAL_TIM_IC_CaptureCallback(TIM_HandleTypeDef *htim)
{
	if(isFirstRead)
	{
		firstRead = HAL_TIM_ReadCapturedValue(htim, TIM_CHANNEL_1);
		isFirstRead = 0;
	}
	else{
		secondRead = HAL_TIM_ReadCapturedValue(htim, TIM_CHANNEL_1);
		isFirstRead = 1;

		if(secondRead > firstRead)
		{
			result = secondRead - firstRead;
		}
		else{
			result = (0xffffffff + firstRead) - secondRead;
		}
	}
}
