7.02  PWM DUTY RANGE LED INDICATOR
=================================

Board      : STM32F407G-DISC1 (Discovery)
Tool       : STM32CubeIDE, HAL
Clock      : HSI 16 MHz (timer clock 16 MHz) unless stated
Debug      : SYS -> Serial Wire, always
Onboard    : PD12 green, PD13 orange, PD14 red, PD15 blue, PA0 user button
             (HIGH when pressed), LIS3DSH accelerometer on SPI1
             (PA5 SCK, PA6 MISO, PA7 MOSI, PE3 CS), internal ADC temp/VREFINT

Source     : extra (classmate solution), class mixed-scenario sheet, Q2 (no external components)

Scenario:
Generate a 1 kHz PWM signal with TIM4 Channel 1 and smoothly sweep its duty
cycle from minimum to maximum and back. No external LED is permitted. The
onboard LEDs must display four approximate duty-cycle ranges while the PWM
registers are inspected through SWD.

Use the following onboard indication:
- 0-24%   : all LEDs OFF
- 25-49%  : PD12 ON
- 50-74%  : PD12 and PD13 ON
- 75-100% : PD12, PD13, PD14 and PD15 ON

Tasks:
1. Configure TIM4 Channel 1 in PWM Generation mode.
2. Use a 16 MHz timer clock and select values for 1 kHz PWM. One suitable
   choice is PSC = 15, giving a 1 MHz counter, and ARR = 999.
3. Start PWM with HAL_TIM_PWM_Start().
4. Change CCR1 periodically so the duty cycle increases and decreases
   smoothly. For ARR = 999, CCR1 values from 0 through 999 represent
   approximately 0% through 100% duty cycle.
5. Update the four onboard LEDs from the calculated duty range without using
   a blocking delay inside an interrupt.
6. Observe CCR1, ARR, CNT and the calculated duty percentage in the debugger.
7. Explain how the PWM duty cycle controls the average power delivered by a
   load and why the onboard LEDs are being used only as a visual range
   indicator in this no-external-components assignment.

======================================================================
SOLUTION
======================================================================

STEP 1 - CubeMX (.ioc) settings
------------------------------------------------------------
SYS               | Debug = Serial Wire
RCC               | default (HSI 16 MHz)
PD12-PD15         | GPIO_Output
TIM4              | Clock Source = Internal Clock, Channel1 = PWM Generation No Output
TIM4 params       | Prescaler 16, Counter Period 1000, PWM mode 1, Pulse 0
Note              | led_handle() turns the LEDs on by duty range.

{
    HAL_GPIO_WritePin(GPIOD, GPIO_PIN_12|GPIO_PIN_13|GPIO_PIN_14|GPIO_PIN_15, GPIO_PIN_RESET);


    if(percentage >= 25 && percentage < 50)
    {
        HAL_GPIO_WritePin(GPIOD, GPIO_PIN_12, GPIO_PIN_SET);
    }
    else if(percentage >= 50 &&  percentage < 75)
    {
        HAL_GPIO_WritePin(GPIOD, GPIO_PIN_12|GPIO_PIN_13, GPIO_PIN_SET);
    }
