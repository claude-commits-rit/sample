7.08  RTC ACCESS EVENT LOGGER
============================

Board      : STM32F407G-DISC1 (Discovery)
Tool       : STM32CubeIDE, HAL
Clock      : HSI 16 MHz (timer clock 16 MHz) unless stated
Debug      : SYS -> Serial Wire, always
Onboard    : PD12 green, PD13 orange, PD14 red, PD15 blue, PA0 user button
             (HIGH when pressed), LIS3DSH accelerometer on SPI1
             (PA5 SCK, PA6 MISO, PA7 MOSI, PE3 CS), internal ADC temp/VREFINT

Source     : extra (classmate solution), class mixed-scenario sheet, Q8 (no external components)

Scenario:
Use the onboard User button as an access-event request. Every valid press
must receive an RTC timestamp and be stored in RAM. The LEDs show activity;
the SWD debugger is used to inspect the stored records. No display or UART
terminal is required.

Tasks:
1. Configure the RTC with an initial date and time using an internal clock
   source such as LSI, so no external crystal or component is required.
2. Keep PD12 ON in the ready state.
3. Configure PA0 as an EXTI input and apply software debounce so one physical
   press creates one event.
4. For each valid press, increment an event counter, read the RTC date and
   time, store the record in a RAM ring buffer, and blink PD13 for 500 ms.
5. Store at least the five most recent event records. Each record must contain
   an event number and date/time fields.
6. When the event count is a multiple of five, blink PD15 three times and
   expose the five records for inspection in the debugger.
7. Use PD14 for an invalid RTC or state error, and document how the error is
   cleared.
8. Test normal presses, a held button, rapid presses, event numbers 5 and 10,
   and RTC rollover at a minute boundary.
9. Keep interrupt handlers short and keep SWD enabled.

======================================================================
SOLUTION
======================================================================

STEP 1 - CubeMX (.ioc) settings
------------------------------------------------------------
SYS               | Debug = Serial Wire
RCC               | default (HSI 16 MHz)
RCC               | LSI ON (RTC clock source = LSI)
PA0               | GPIO_EXTI0, Rising edge, No pull
PD12-PD15         | GPIO_Output
RTC               | Activate Clock Source + Activate Calendar, 24 h, Asynch 127, Synch 255,
                  | start time 22:00:00, date 29 Oct
NVIC              | EXTI line0 interrupt = ticked
------------------------------------------------------------

void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
    if (GPIO_Pin == GPIO_PIN_0)
    {
        uint32_t current_time = HAL_GetTick();

        // Software Debounce: Ignore extra edges within 200ms of the first press
        if ((current_time - last_interrupt_time) > 200)
        {
            button_pressed_flag = 1;
            last_interrupt_time = current_time;
        }
    }
}
